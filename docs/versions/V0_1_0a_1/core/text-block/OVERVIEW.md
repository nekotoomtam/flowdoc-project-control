# Text Block Documentation Overview

## Authority and Status

Text Block documentation synthesis is complete across three bounded leaves and
one family overview. Text Block and parent Core remain `unknown`; these
documents do not establish family promotion, migration execution, publication,

## Dependency Chain

`v1 grammar and migration history` -> `v4 authoring and inline` -> `v4 measurement and pagination`

## Responsibility Boundaries

The V1 leaf owns historical grammar, pure normalization, accepted-write
alignment, and the copy-forward migration decision. The V4 authoring leaf owns
the flat-inline grammar, selection identity, explicit command planning, and
single-user whole-rich-inline replacement boundary. The measurement and
pagination leaf owns resolved measurement source points, accepted line ranges,
isolated page fragments, and the bounded close-audit result.

Input surfaces, collaboration-safe deltas, persistence, shaper execution,
mixed-document composition, renderer and export integration, backend jobs,
cross-page editing, and general performance readiness remain outside these
documents.

## Evidence Flow

Version-policy and accepted-write Evidence bound the V1 transition record.
Authored-contract and rich-inline replacement Evidence bound the V4 authoring
record. Measurement/pagination and close-audit Evidence bound the final leaf.
Each claim remains limited to its pinned Core executable anchor.

## Current Verified State

The reviewed leaves preserve active package-v2/document-v3 acceptance and a
