# Text Block Documentation Family Frame

Family state: `unknown`

Documentation state: `candidate`

This compact frame preserves the reviewed Text Block lane boundaries without
promoting historical or candidate documentation into current product truth.
Detailed contracts remain with the three lane leaves. Task 5 alone performs final family reconciliation after the three lane reviews.

## Dependency Direction

`v1 history` -> `v4 authoring` -> `v4 measurement/pagination`

Each lane may rely on the preceding lane's bounded documentation context, but
no lane transfers ownership or turns a candidate claim into family authority.

## Ownership and Limits

| Lane | Owns | Explicitly excludes |
| --- | --- | --- |
| V1 history | Historical grammar and migration reasoning | Current v4 authority, parser or migration activation, and readiness claims |
| V4 authoring | Candidate authored-inline and commit-boundary contract | Input surfaces, collaboration, persistence, measurement, pagination, and renderer authority |
| V4 measurement/pagination | Candidate resolved-range and isolated-fragment contract | Shaper selection or execution, mixed composition, renderer or export, backend lifecycle, and cross-page editing |

## Unknown and Excluded Claims

No lane establishes current product truth, migration coverage, or source-cleanup authority.
Current runtime behavior, product readiness, publication, shared registration,
and any source disposition remain unknown or excluded from this frame. This
overview neither authorizes cleanup nor records coverage; it is navigation for
candidate lane work only.
